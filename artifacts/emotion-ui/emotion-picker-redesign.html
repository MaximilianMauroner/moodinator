What is wrong today

The selected-emotion band is the main offender

  • reserveSummarySpace holds a fixed 82 dp band plus a 16 dp margin, whether or not anything is selected.
  • Its chips use min-h-12 min-w-12 (48 dp) and rounded-full, so two short words become large floating pills in an otherwise empty strip. That is the part that reads as broken.
  • The information is already duplicated three ways: the 2/3 selected badge, the filled grid chip, and the tick.

Chips are sized for a 14 px label but drawn at 48 dp

  • min-h-12 forces 48 dp for a 17 dp line box, so roughly 64% of every chip is padding.
  • With an 8 dp gap the row pitch is 56 dp. Four rows of Positive alone cost 224 dp.
  • Category headers add a divider, 5 dp padding, 10 dp margin and a 16 dp block margin: ~32 dp of chrome each, three times over.

The three directions

A — Dense grid

  • Smallest change. Same browsing model, same components.
  • Chip 36 dp, gap 7 dp, label 13.5 px.
  • Fixed 82 dp band replaced by a 34 dp single-line strip that keeps its height when empty, so nothing jumps.
  • Selected chips now match the grid chips: 10 dp radius, not pills.

B — Category tabs

  • One category at a time, tabs pinned at the top. The tabs work — click them.
  • Per-tab badge shows how many of your 3 picks sit in that category, so nothing is hidden.
  • measuring…
  • Costs one tap to reach another category, and it is the only option that changes how you browse.

C — Docked selection

  • Selection moves out of the scroll area and docks above Cancel / Next, where it is always in view.
  • The scroll area starts straight at the chips: zero space before the first one.
  • Chip 32 dp, the tightest of the three.
  • Footer grows by 44 dp, which is why it does not beat B outright.

Implementation spec (whichever you pick)

Touch targets stay legal. Dropping min-h-12 shrinks the drawn chip, not the tappable one. Add hitSlop={{top: 6, bottom: 6, left: 3, right: 3}} to the chip Pressable: 36 + 12 = 48 dp effective height, and the 6 dp slop stays inside the 7 dp row gap so neighbouring targets never overlap. For the 32 dp chip in C use hitSlop of 8 top and bottom with an 8 dp row gap.

EmotionPicker.tsx

  • Chip: min-h-12 min-w-12 px-3 py-2 rounded-xl → min-h-9 px-[11px] rounded-[10px], label text-[13.5px].
  • Grid: gap-2 → gap-x-[7px] gap-y-2.
  • Summary: drop minHeight: 82, use a fixed 34 dp row. Keep the reserved height so the empty and filled states do not shift the grid.
  • Selected chip: min-h-12 rounded-full → h-7 rounded-[9px], matching the grid chip radius.
  • Category header: drop borderBottomWidth, use a 22 dp row with a hairline rule and an item count; block margin mb-4 → mb-3.5.

Unchanged on purpose

  • Colour tokens, selected/disabled semantics, tick badge, and the maxSelections limit behaviour.
  • Press spring, haptics.tick(), and accessibility labels.
  • Light theme uses the same numbers; only the tokens differ, so parity holds.
  • No new animation. Nothing here repaints continuously.
